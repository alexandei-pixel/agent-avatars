# agent-avatars

Profile pictures for the KinoSec `#ai-agents` Slack personas.

These are **AI-generated faces of fictional, non-existent people**, used purely as avatars for the
team's automated agents. They do not depict any real individual.

Currently holds `tel.jpg` only. The other five personas (Marcus, Priya, Diego, Nora, Vivian) are
served from `alexis-kinosec/agent-avatars`; this repo exists because that one is read-only to this
account. Merge the two when write access is available — it is a one-line `ICON_URL` change in each
persona's `persona.md`.

Each avatar is 512x512 JPEG, served to Slack as `icon_url`.
